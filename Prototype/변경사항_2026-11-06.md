# 2026-11-06 설정 UI·사진 파일명 수정

전체 요구사항을 구현한 버전이 아닙니다. 이번 변경은 요청의 1·2·8번에 해당합니다.
4번의 일반 일정 입력 방식은 유지했습니다. 3·5·6·7·9·10·11·12·13번은 반영하지 않았습니다.
카메라·방위각과 연결된 인원/선박 위치 및 상태관리 기능은 포함하지 않습니다.

## 반영 사항

- 환경설정의 기록장 이름 표시를 `구간 명 (예시: 4구간)`으로 변경했습니다.
- 새 설정의 이름 기본값은 빈칸입니다. 기존 이름은 바꾸지 않습니다.
- CSV 출력 경로와 사진 할당 경로에 각각 찾아보기 버튼을 추가했습니다.
- 직접 입력도 가능하며 폴더 선택 취소 시 기존 경로를 유지합니다.
- 사진 이동 버튼을 `사진할당`으로 변경했습니다. 실제 동작은 기존처럼 이름 변경과 이동입니다.
- 연결 사진 한 장에는 `(1)`을 붙이지 않습니다. 여러 장에는 연결 순서에 따라 `(1)`, `(2)`를 붙입니다.
- 기존 한 장짜리에 추가 사진을 할당하면 기존 파일도 번호를 붙여 정리합니다.
- 일부 할당이 실패하면 성공한 연결 목록을 기준으로 이름을 다시 정리합니다.
- 다른 파일과 이름이 충돌하면 원본과 기존 파일을 남기고 오류를 표시합니다.
- 예전 한 장짜리 사진의 `(1)`은 사진명 갱신 버튼으로 제거할 수 있습니다.

사진 개수와 번호는 기록에 연결된 목록 기준입니다. 사용자가 이미 지운 파일의 연결도 남아 있으므로
파일 없음 상태를 별도로 표시합니다. 사진 보존 기간에 따른 삭제는 계속 사용자가 담당합니다.
기록 영구 삭제 시 사진 파일은 남습니다.

## 적용

실행 중인 프로그램을 종료하고 `Core.cs`, `Dialogs.cs`, `MainForm.cs`를 교체합니다.
`Program.cs`와 `Build.vbs`는 이전 버전 그대로 사용합니다. 기존 `Data` 폴더를 지우지 마세요.
`Build.vbs`를 실행한 뒤 가상 기록과 사진 복사본으로 확인하세요.
XML 저장 형식은 바꾸지 않았습니다.

- 핵심 데이터 시험 27개: 통과.

UI 시험은 폴더 선택 버튼의 존재·경로 직접 편집·레이블·렌더링과
사진 이름 변경 후 XML 연결 갱신, 한 장에서 두 장 전환, 반복 실행,
충돌 시 파일 보존 및 충돌 해소 후 재시도 등을 확인했습니다.
실제 Windows의 폴더 선택/취소 대화상자와 VBS 실행은 여기서 시험하지 못했습니다.
배포 프로그램 자체는 외부 라이브러리를 사용하지 않습니다.
